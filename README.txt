KUSHAN PRIYADASUN — PORTFOLIO WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the website.
3. To publish free, upload the contents of this folder to GitHub Pages, Netlify or Cloudflare Pages.
4. Your CV is included at assets/Kushan-Priyadasun-CV.pdf.

CUSTOMISE
- Edit text and contact details in index.html.
- Change colours, layout and typography in style.css.
- Edit interactions in script.js.
- Replace images in assets/images/ if you want to use other portraits.

NOTES
- The LinkedIn button has not been added as a destination because the CV only contained the word “LinkedIn”, not a profile URL.
- Your street address and referee contact details have been omitted from the public portfolio for privacy.
- The Queensland Health role is presented as your current role; add exact start date if you want it shown.
